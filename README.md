# 科学上网控制台 · Dr.Wan Net Console

> 一个 Windows 上的「点一下就能开、点一下就能关」的本地代理控制台。
> 界面中文、托盘常驻、订阅一键更新。**免费开源，节点自备。**

![界面](docs/screenshot.png)

## 这是什么

一个包了层好看外壳的 [mihomo](https://github.com/MetaCubeX/mihomo)（Clash.Meta 内核）控制台：

- **能看见状态**：内核在不在跑、代理端口通不通、节点延迟多少，一目了然。
- **不用敲命令**：开启/关闭系统代理、切换节点、测速、更新订阅，全是按钮。
- **关了窗口还在跑**：点关闭是最小化到托盘，代理不断；真要退出走托盘右键菜单。
- **不写注册表、不装服务**：整个文件夹拷走就能在别的电脑上用。
- **订阅能自己换**：默认拉公开的免费节点列表，有自己的机场就改订阅源文件。

内核固定用 `7890`（HTTP/SOCKS 混合代理）和 `9090`（本地控制接口，只监听 127.0.0.1）。

## 三步上手

1. **解压** 整个文件夹到任意位置（路径别带特殊符号，例如 `D:\Tools\net-console`）。
2. **先跑一次**「解除锁定.cmd」（Windows 会锁住从网上下载的脚本）。
3. **双击**「启动控制台.cmd」→ 点「立即更新」拉节点 → 点「开启系统代理」。

> 想换自己的订阅：把订阅链接一行一个写进 `subscription-sources.txt`，再点一次「立即更新」。
> 脚本会先下载 → 让内核校验 → 备份旧配置 → 原子替换 → 重启内核；任何一步失败都保留原配置。

## 文件说明

| 文件 | 作用 |
| --- | --- |
| `mihomo.exe` | 内核本体（v1.19.34，windows amd64，with_gvisor）。GPL-3.0，见 `LICENSE-mihomo.txt` |
| `console.ps1` | 控制台界面（WPF，中文）。状态刷新、托盘、日志都在这 |
| `console-hidden.vbs` | 无黑窗启动器，用 wscript 拉 PowerShell |
| `update-subscription.ps1` | 订阅更新：多镜像回退、内核校验、备份、替换、重启、自动选最快节点 |
| `subscription-sources.txt` | 订阅源列表，一行一个。默认是公开的 NoMoreWalls 镜像，不含任何私人 token |
| `config.template.yaml` | **空配置模板**：只有端口/DNS/分流骨架 + `proxies: []`，无任何节点 |
| `GeoIP.dat` / `GeoSite.dat` / `country.mmdb` | 分流规则库 |
| `tray.ico` | 托盘图标 |
| `start.ps1` / `stop.ps1` | 纯脚本启停内核（不依赖 GUI，出问题时的兜底） |
| `启动控制台.cmd` | 主入口 |
| `启动内核.cmd` / `停止内核.cmd` | 兜底入口 |
| `解除锁定.cmd` | 首次运行前解除 Windows 文件锁 |
| `使用说明.txt` | 给最终用户看的说明（含常见问题） |

## 系统要求

Windows 10 / 11 x64。需要系统自带的 Windows PowerShell 5.1（默认就有）。
不需要装 .NET、Python、Node，也不需要联网安装依赖。

## 换内核 / 换端口

- 换内核：把新的 `mihomo.exe` 覆盖进来即可，控制台只按文件名找它。
- 换端口：改 `config.template.yaml` 里的 `mixed-port`，同时改 `console.ps1` 顶部的代理端口变量与 `start.ps1` 里的端口检查。
- 控制接口加密码：在配置里填 `secret`；控制台目前固定无密码访问 127.0.0.1:9090（只监听本机，风险有限）。

## 常见问题

**双击没反应？** 先跑「解除锁定.cmd」。还不行就用「启动内核.cmd」看报错。

**端口被占用？** 本工具固定用 7890 / 9090。装了别的 Clash / v2rayN，先把它们关掉。

**节点全不通？** 点「立即更新」重拉；免费列表失效是常态，多试几次或换成自己的订阅。

**杀毒软件报警？** 因为是无签名的开源内核，加信任即可。源码全在这，可以自己比对。

**关掉代理后上不了网？** 控制台启动时会检测「系统代理指向一个没跑的内核」这种残留并自动还原。真遇到：设置 → 网络 → 代理 → 关掉手动代理。
